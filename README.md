# 🎨 Color Pool Puzzle 
Посетите [наш сайт](https://ziadik.github.io/color_ball_puzzle_svelte/)


Color Pool Puzzle — это логическая игра-головоломка, где нужно направлять цветные шарики в соответствующие лунки, используя различные типы стен и препятствий.

## 🎮 Как играть

1. **Цель игры** — переместить все шарики в лунки соответствующего цвета
2. **Управление** — проведите пальцем или мышкой от шарика в направлении движения
3. **Механика** — шарик движется по прямой, пока не встретит препятствие или не попадет в лунку
4. **Победа** — когда все шарики оказались в лунках своего цвета

## 🛠️ Редактор уровней

Редактор уровней позволяет создавать и редактировать игровые уровни в визуальном режиме.

### 📋 Возможности редактора

- **Рисование стен** — выбор любого типа стены из панели инструментов
- **Размещение шариков** — 6 цветов на выбор
- **Размещение лунок** — 6 цветов на выбор
- **Установка блоков** — непроходимые препятствия
- **Ластик** — удаление любых элементов
- **Изменение размера** — от 5×5 до 20×20 клеток
- **История действий** — отмена и повтор (Ctrl+Z / Ctrl+Shift+Z)
- **Импорт/Экспорт** — загрузка и сохранение уровней в JSON

### ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `1` | Инструмент "Стена" |
| `2` | Инструмент "Шарик" |
| `3` | Инструмент "Лунка" |
| `4` | Инструмент "Блок" |
| `5` | Ластик |
| `Ctrl+Z` | Отменить действие |
| `Ctrl+Shift+Z` | Повторить действие |
| `J` | Показать JSON уровня |
| `L` | Показать/скрыть панель слоев |
